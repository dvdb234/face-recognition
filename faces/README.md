# Reference photos go here

Drop **one clear, front-facing photo per person** into this folder. The file
name (minus the extension) becomes the label shown on screen:

| File                | Label shown |
|---------------------|-------------|
| `david.jpg`         | `David`     |
| `alex.jpg`          | `Alex`      |
| `alex_smith.png`    | `Alex Smith`|

Tips for good recognition:

- Use a sharp, well-lit photo where the face is large and roughly front-on.
- One face per photo. If a photo has several faces, only the first is used.
- `.jpg`, `.jpeg`, `.png`, `.bmp`, and `.webp` are all accepted.
- You can add or remove photos any time; they are loaded when the program starts,
  so restart it after changing this folder.

Anyone whose face doesn't match a photo here is labelled **`Unknown`**.
